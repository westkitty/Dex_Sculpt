# Provenance and licensing

## Code in this repository

DEX//SCULPT's source is original work for this project and is released under the
MIT licence in [LICENSE](../LICENSE). No upstream application code is vendored:
FORM//ENGINE, DEX//RIG and the humanoid catalog were read as references for
interaction design and data shape, and the implementations here were written
against Three.js and the browser APIs directly.

Runtime dependency: **three@0.186.1** (MIT) with its official examples
(`OrbitControls`, `RoomEnvironment`, `GLTFLoader`, `GLTFExporter`, `SkeletonUtils`).
Development dependencies (Vite, TypeScript, Vitest, Playwright, jsdom) are MIT or
Apache-2.0; see `package-lock.json` for the exact tree.

## Humanoid catalog metadata

`public/catalog/humanoid-summary.json` is generated by
`tools/catalog/build-summary.mjs` from the public catalog branch of
[modern_3d_browser_game_toolkit](https://github.com/westkitty/modern_3d_browser_game_toolkit/tree/feat/humanoid-asset-catalog-20261113/catalog/humanoids).

- It contains **metadata only**: asset ids, names, types, skeleton families, joint
  and clip counts, upstream licence labels, QA notes and compatibility notes.
- It contains no binaries, no private storage identifiers, no signed URLs and no
  content hashes of restricted files.
- The sanitiser in the builder strips free-text notes that could contain storage
  locators before the file is written.
- Upstream licence labels are reproduced as recorded by the catalog
  (Rocketbox MIT, CC0/MIT packs, GDQuest CC-BY-4.0 etc.). They are **not** a
  substitute for verifying the licence of a file you actually load. DEX//SCULPT
  never fetches those files; the user relinks a local file they are licensed to
  use, and the recipe records the licence string that was known at the time.

## Upstream references (read-only)

- **FORM//ENGINE** (browser sculpting, tablet interaction) — reference for brush
  set, stroke transactions and the known defect where rigged-model sculpt import
  drops skinning and morph targets. DEX//SCULPT's delta-layer design exists
  specifically to avoid inheriting that defect.
- **DEX//RIG** — a separate **2D** layered character animation workbench. It is not
  a 3D mesh or skeleton system and is not integrated here; any relationship is
  future-facing and documented as such in ARCHITECTURE.md.
- **Humanoid Character Library** — metadata, skeleton-family compatibility and QA
  notes. Its licensed model binaries live in a private archive and are deliberately
  not redistributed.

No modifications were made to those repositories, and no changes to them are
required to use DEX//SCULPT.

## If you add an asset

Before committing any model, texture or animation data:

1. Confirm its licence permits public redistribution, and record the licence and
   source URL in this document.
2. Prefer original or CC0 content for demos and tests.
3. Never commit private archive identifiers, signed URLs, credentials or personal
   source images.
